# AI相談UX改善機能設計

**作成日:** 2026年2月19日
**ステータス:** ✅ 設計完了・実装待ち

---

## 📋 要件概要

現在のAI相談機能（summarize / opinion / next_action ボタン）と、ユーザー入力の組み合わせを刷新。

### 主な変更点

1. **「AI相談」ボタン群の廃止**
   - 現在の AIHelperButtons（summarize / opinion / next_action）を廃止
   - 代わりにユーザーが**入力欄で自由に質問内容を指定**できる方式に変更

2. **チャット/CANVASの明示的な選択と表示**
   - チャット選択時：入力欄に**選択中のチャットの先頭15文字**を表示
   - CANVAS選択時：入力欄に**「CANVAS」**を表示
   - **送信ボタンを非表示**にして、**AI送信ボタンのみ表示**
   - 両者とも**チェックボックス＋強調表示**で選択状態を可視化

3. **AI送信ボタンでの一元化**
   - 入力欄の「AI送信」ボタンで統一
   - 選択したチャット/CANVASに対して、ユーザーが入力した内容でAIに問い合わせ

## 🔍 実装の詳細要件

### 1️⃣ AI相談ボタンの廃止

**対象ファイル:** `AIHelperButtons.tsx`

- 現在の 3つのボタン（summarize / opinion / next_action）を**削除**
- `MessageInput.tsx` の「AI送信」ボタンのみを使用

---

### 2️⃣ 選択状態表示エリア（新規追加）

**対象ファイル:** `MessageInput.tsx` 上部、または専用コンポーネント化

**配置：**

```
┌─────────────────────────────────────┐
│ 🎯 選択中: Chat B の先頭15文字      │  ← 参照用エリア（編集不可）
│ または CANVAS                       │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ [テキストエリア: 質問を入力...]     │  ← ユーザー入力欄
│ [AI送信]                            │  ← 送信ボタン（通常送信は非表示）
└─────────────────────────────────────┘
```

**実装内容：**

- **バッジ型**で「選択中のチャット/CANVAS」を表示
- ユーザーが選択を変更すると、リアルタイムで内容が更新される
- 編集可能ではない（読み取り専用のバッジ）

**表示内容の仕様：**

- チャット選択時：バッジ「Chat B: お疲れ様です...」（先頭15文字）
- CANVAS選択時：バッジ「CANVAS」
- 未選択時：グレーアウトしたプレースホルダー「選択してください」

**表示位置の推奨配置：**

```
┌────────────────────────────────────┐
│ [Chat B: お疲れ様です...] ← バッジ │
└────────────────────────────────────┘

┌────────────────────────────────────┐
│ [テキストエリア: 質問を入力...]    │
│ [AI送信]                           │
└────────────────────────────────────┘
```

---

### 3️⃣ チャット選択機能の強化

**対象ファイル:** `ConversationClient.tsx` / `ChatSidebar.tsx`

#### 現在の状況

- ✅ チャット選択機能は既に実装されている
- ❓ CANVASセクションとも連動させるか確認が必要

#### 実装内容

**チャット選択時：**

- チェックボックス＆強調表示で選択状態を表示
- `selectedChat` 状態を管理
- 選択状態表示エリアに先頭15文字を表示

**CANVAS選択時（新規）：**

- **CANVASセクション全体をクリック可能に改修**（チェックボックスは視認性向上のため表示）
- セクション全体をクリックすると選択状態がトグルされる
- 選択状態表示エリアにバッジ「CANVAS」を表示
- プロンプト種別選択も連動

**選択状態の排他性・解除ロジック：**

- チャット OR CANVAS いずれか1つのみ選択可能
- 一方を選択すると、他方の選択は**自動的に解除される**
- **選択済みのチャット/CANVASをもう一度クリックすると選択解除される**（トグル動作）
- 選択解除時：バッジはグレーアウト状態に戻る

---

### 4️⃣ 送信ボタンの制御

**対象ファイル:** `MessageInput.tsx`

```tsx
<MessageInput
  value={userInput}
  onSend={onSend}
  onAISend={onAISend}
  hideNormalSend={true} // ← 新規オプション：送信ボタンを非表示
/>
```

- **送信ボタン（通常）：** 非表示
- **AI送信ボタン：** 常時表示（ユーザー入力がある場合のみ有効）
- 選択状態がない場合：「AI送信」ボタンは無効化

---

### 5️⃣ AI送信時のロジック

**対象ファイル:** `ConversationClient.tsx` / バックエンド API

#### メッセージ送信時の処理

```tsx
async function handleAISend() {
  // チャット選択時：そのチャットに AI メッセージを追加
  if (selectedChat) {
    const request = {
      conversationId: selectedChat.conversationId,
      actionType: "answer",
      userInput: userInput,
    };
    await sendAIMessage(request);
  }

  // CANVAS選択時：現在の会話に対してCanvasのプロンプトを反映したAI処理
  if (selectedCanvas) {
    const request = {
      conversationId: currentConversation.conversationId,
      actionType: "answer",
      userInput: userInput,
      selectedPromptType: selectedCanvas.selectedPromptType,
      customPromptText: selectedCanvas.customPromptText,
    };
    await sendAIMessage(request);
  }
}
```

**バックエンド側の対応：**

- 既存の `answer` アクションをサポート
- `userInput` をそのまま AI に送信
- CANVAS選択時は、プロンプト種別に応じた前処理を実施（必要に応じて）
