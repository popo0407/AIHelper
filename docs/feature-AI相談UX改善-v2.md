# AI相談UX改善機能設計 - 最終版

**作成日:** 2026年2月19日
**ステータス:** ✅ 設計完了・実装中

---

## 📋 要件概要

現在のAI相談機能（summarize / opinion / next_action ボタン）と、ユーザー入力の組み合わせを刷新。

### 主な変更点

1. **「AI相談」ボタン群の廃止**
   - 現在の AIHelperButtons（summarize / opinion / next_action）を廃止
   - 代わりにユーザーが**入力欄で自由に質問内容を指定**できる方式に変更

2. **チャット/CANVASの複数同時選択**
   - **複数のチャット ＆ CANVAS を同時に選択可能**
   - 例：Chat A + Chat C + CANVAS を同時選択
   - 選択状態表示エリアに**選択中のすべてを表示**
   - 何が選択されているか明確に可視化

3. **AI送信ボタンでの一元化**
   - 統一されたメッセージ入力欄の「AI送信」ボタンで送信
   - 選択されたすべてのチャット/CANVASに対して、同じ質問を送信

💡 **選択動作（クリックベース）：**

- Chat A をクリック → 「Chat A」を選択状態に追加
- Chat C をクリック → 「Chat A, Chat C」と表示
- CANVAS をクリック → 「Chat A, Chat C, CANVAS」と表示
- Chat A をもう一度クリック → 「Chat C, CANVAS」と表示（Chat A 削除）

## 🔍 実装の詳細要件

### 1️⃣ AI相談ボタンの廃止

**対象ファイル:** `AIHelperButtons.tsx`

- **完全削除**：表示不要
- コンポーネント自体を削除、または使用箇所から削除

---

### 2️⃣ 選択状態表示エリア（新規追加）

**対象ファイル:** `MessageInput.tsx` 上部

**配置：**

```
┌────────────────────────────────────────────┐
│ 選択中: Chat A, Chat C, CANVAS             │ ← 参照用（読み取り専用）
│ （選択がない場合：グレー「選択してください」│
└────────────────────────────────────────────┘

┌────────────────────────────────────────────┐
│ [テキストエリア: 質問を入力...]            │
│ [AI送信]                                   │
└────────────────────────────────────────────┘
```

**実装内容：**

- テキスト形式で「選択中: Chat A, Chat C, CANVAS」を表示
- 選択対象が変更されるたびに動的に更新
- 編集可能ではない（読み取り専用）
- 選択がない場合：「選択してください」とグレーアウト表示

---

### 3️⃣ チャット選択機能の強化

**対象ファイル:** `ConversationClient.tsx` / `ChatSidebar.tsx`

**チャット選択時（クリックベース）：**

- 既存のチャッククリック機能を活用
- クリックするたびにON/OFF状態を切り替え
- 選択状態を `selectedChats: Conversation[]` で管理
- 選択されたすべてのチャットを追跡

**CANVAS選択時（新規）：**

- CANVAS セクション全体、または CANVAS テキスト/アイコンをクリック可能
- クリックするたびにON/OFF状態を切り替え
- 選択状態を `isCanvasSelected: boolean` で管理
- CANVASは複数選択ではなく ON/OFF のトグル（選択状態は0または1個）

**選択状態の管理：**

- チャット複数選択：クリックで任意に ON/OFF 可能
- CANVAS：クリックで ON/OFF 切り替え
- 選択状態表示エリアに「Chat A, Chat C, CANVAS」とすべてを列挙

---

### 4️⃣ 送信ボタンの制御

**対象ファイル:** `MessageInput.tsx`

```tsx
<MessageInput
  value={userInput}
  onChange={onInputChange}
  onSend={onSend}
  onAISend={onAISend}
  hideNormalSend={true} // ← 通常の送信ボタンを非表示
  disabled={!hasSelection} // 選択がない場合は無効化
/>
```

- **送信ボタン（通常）：** 非表示
- **AI送信ボタン：** 常時表示（選択かつユーザー入力がある場合のみ有効）

---

### 5️⃣ AI送信時のロジック

**対象ファイル:** `ConversationClient.tsx` / バックエンド API

#### メッセージ送信時の処理

```tsx
async function handleAISend() {
  // すべての選択コンテンツを集約
  const aggregatedContent: string[] = [];

  // チャット選択がある場合、各チャットの内容を集約
  for (const chat of selectedChats) {
    aggregatedContent.push(chat.content); // チャットのテキスト内容
  }

  // CANVAS選択がある場合、CANVASに表示されているテキストを集約
  if (isCanvasSelected) {
    aggregatedContent.push(canvasDisplayContent); // CANVASパネルに表示されているテキスト
  }

  // 集約されたコンテンツとユーザー入力を合わせて1回のリクエストで送信
  const request = {
    actionType: "answer",
    userInput: userInput,
    context: aggregatedContent.join("\n---\n"), // 区切り文字で複数内容を連結
  };

  await sendAIMessage(request);
}
```

**動作：**

- 選択されたすべてのチャット＆CANVASの内容を集約して、1回のリクエストで AI に投げる
- 例：Chat A + Chat C + CANVAS が選択 → 1回の AI リクエスト（内容を組み合わせたもの）

**バックエンド側の対応：**

- 既存の `answer` アクションをサポート
- `userInput` と集約された `context`（各チャット・CANVAS内容）を合わせて AI に送信

## ✅ 仕様確定事項

1. **選択モデル：** ✔️ **複数同時選択可能**
   - チャット：複数チェック可能
   - CANVAS：ON/OFF のみ（同時に1個）

2. **表示形式：** ✔️ **すべてを列挙**
   - 「Chat A, Chat C, CANVAS」のように選択中のすべてを表示

3. **AI送信：** ✔️ **すべてに送信**
   - 選択されたすべてのチャット/CANVASに同じ質問を送信

4. **情報送付：** ✔️ **内容集約で送付**
   - 選択済みチャット・CANVAS のテキスト内容を集約
   - `userInput` とともに AI に送信
   - `conversationId` は不要
